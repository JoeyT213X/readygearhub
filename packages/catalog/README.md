# @omega/catalog

Shared catalog for ReadyGearHub and the Omega company hub: affiliate programs, paid-search guard, product index, offers, workbench handoff URLs, and the legal name (OMEGA UCO SOLUTIONS, LLC — change it only in `organization.ts`; see LEGAL_NAME.md).

Edit `affiliates.ts` to flip a program live. Edit `organization.ts` to change the LLC name (one value, both sites). Run `npm run test:paid-guard` from the ReadyGearHub repo root before merging.
