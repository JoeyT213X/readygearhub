# ReadyGearHub

Bot-run, directory-style gear hub (Astro static site, hosted on Netlify).

```bash
npm install
npm run dev          # local preview at http://localhost:4321
npm run build        # outputs dist/
npm run check-links  # verify every product URL
```

See **[BOTS.md](./BOTS.md)** for how to add listings, re-rank trending items, add lanes and niches, write guides, and deploy.
